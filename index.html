Quitar Marca de Agua

Subí una imagen, marcá con el mouse (clic y arrastrá) el rectángulo que cubre la marca de agua o el logo, y aplicá "Quitar marca". Rellena esa zona a partir de la textura de los bordes cercanos — anda bastante bien en fondos lisos o con textura pareja (cielo, pared, degradé), pero en fondos complejos puede quedar borroso justo ahí. No usa ninguna IA ni servicio externo, es matemática local con canvas — si querés una reconstrucción perfecta tipo IA generativa, eso sí necesitaría una API paga aparte (no está incluida acá).

Hacé clic para elegir la imagen o arrastrala acá.

Editar Colores

Subí un PNG, JPG o GIF. Si el GIF tiene movimiento se mantiene en la vista previa animada; si la imagen tiene transparencia, se respeta. Los cambios de tono/saturación/luz/sombra/contraste se ven en vivo. Ojo: si el original es un GIF animado, se descarga como WEBM (no hay codificador de GIF acá), y la transparencia en ese WEBM depende de que tu navegador la soporte al grabar.

Hacé clic para elegir la imagen o arrastrala acá.

Ejecutar Python

Subí un .py (o pegalo abajo) y lo corremos acá con Pyodide — Python compilado a WebAssembly, corre en tu navegador, no se manda a ningún servidor. La primera vez tarda porque baja el intérprete. Si el script importa librerías como Pillow, numpy, pandas, etc. tratamos de instalarlas solas — las que Pyodide trae precompiladas andan directo, el resto se intenta bajar de PyPI con micropip si es puro-Python. No va a poder abrir ventanas (tkinter), sockets, ni tocar tu disco real: solo lee los archivos que le subas acá abajo y escribe en una carpeta virtual, de la que después descargás lo que haya generado.

Hacé clic para elegir un .py o arrastralo acá (también podés pegar el código abajo).

(Opcional) Archivos que el script necesita leer — clic o arrastrá acá.

Galería de Enlaces

        

          Se arma sola a partir de un archivo reaper-links.json que subís junto a este HTML en tu repo de
          GitHub. Cada vez que edites ese archivo y actualices la web, los botones se actualizan solos — no hace
          falta tocar este HTML. Formato del archivo (una lista de objetos):
        

        
[
  { "nombre": "Twitter", "vector": "https://tu-link-al-icono.svg", "web": "https://twitter.com/tu_usuario" },
  { "nombre": "Discord", "vector": "https://tu-link-al-icono.png", "web": "https://discord.gg/tu-server" }
]

        

          "vector" es el link a la imagen del ícono (svg, png, lo que sea), "web" es a dónde te lleva el botón, y
          "nombre" es la palabrita que aparece abajo por si te olvidás qué es. Ojo: esto solo funciona subido a
          GitHub Pages (o cualquier servidor) — abriendo el HTML como archivo local en tu compu el navegador no te
          va a dejar leer el .json por seguridad.
